# Этап 9. Локальная альфа 0.1.3

18 ноября 2026 года подготовлен пакет `build/alpha-0.1.3/`. В нём VST3 для Windows x64, руководство на русском со стартовыми настройками и порядком отката, а также список изменений.

Для пакета использована проверенная Release-сборка 0.1.3. Бинарник и метаданные побайтно совпали с установленной копией в системной папке VST3. Для этой операции установка не потребовалась.

Стартовые настройки представлены таблицей в руководстве. Отдельных импортируемых файлов пресетов в пакете пока нет. Для приёмки этапа требуется подтверждение пользователя, что 0.1.3 открывается в его REAPER.

## Версия следующей сборки

Для следующей сборки выбран номер 0.1.4. Он задан в `CMakeLists.txt` и передаётся в метаданные VST3 и на шильдик редактора при сборке.

18 ноября добавлена команда `tools/bump_version.py` для расчёта и записи следующего номера по типу релиза. По умолчанию она показывает результат без записи. Для 0.1.4 проверены четыре расчёта: исправление → 0.1.5, новая возможность и несовместимость в альфе → 0.2.0, явный стабильный выпуск → 1.0.0. Правила описаны в [порядке версионирования](../VERSIONING.md).

## Отзыв о настройках баса

Из трёх настроек пользователь предпочёл 60 Гц / Boost 2 / Attenuation 0. При нулевых значениях эффект на слух не ощущался. Настройка 60 Гц / Boost 7 / Attenuation 3 добавляла слишком много низа для этого баса, хотя характер усиления понравился своей мягкостью. Предпочтительная настройка отмечена в руководстве.
