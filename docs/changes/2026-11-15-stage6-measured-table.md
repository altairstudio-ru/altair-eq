# Интерполяция v2 с измеренными обучающими опорами

15 ноября 2026, 44,1 кГц. Проверена гипотеза о совместном влиянии ошибок опор. Для каждого CPS прогноз построен из Flat, 20 одиночных настроек и 23 обучающих совместных настроек. Правило исходной v2 сохранено: сумма комплексных осевых откликов за вычетом Flat плюс кубическая RBF-интерполяция совместной поправки. Входные опоры восстановлены с абсолютной комплексной погрешностью менее 1e-10. Измерения остальных настроек использованы для сравнения после расчёта таблицы.

Дробный контроль CPS 60 / 0,5 / 10: 0,20828 / 0,03185 / 0,04304 дБ и 1,05679°. Порог в басу превышен на 0,00828 дБ. В прежней диагностике кубическая интерполяция по четырём непосредственно измеренным целым точкам давала 0,17994 дБ. Здесь часть этих точек сама предсказана по разреженной обучающей сетке. Последовательность двух интерполяций расходует оставшийся запас.

Вывод ограничен офлайн-прогнозом комплексных откликов в диапазоне SPEC. Целая сетка достижима с данным правилом интерполяции при точных опорах.
