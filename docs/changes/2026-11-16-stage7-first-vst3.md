# Первый сквозной рендер AltaiR EQ LF

16 ноября 2026. Этап 7 начат. Отправная точка — коммит DSP `04d94f3`.

В `CMakeLists.txt` добавлена опциональная цель JUCE. В `plugin/Processor.cpp` оболочка передаёт параметры принятому FrozenLfBank. Для первого хостового теста выбран штатный редактор JUCE. Параметры, обход и сохранение описаны в [формате состояния](../STATE_FORMAT.md), команды приведены в [инструкции сборки](../BUILD_AND_TEST.md).

Release x64 собран. Измерительный хост загрузил пакет и отрендерил стереоимпульс с разными уровнями и полярностью каналов, блок 512, LF 60 CPS, Boost 7, Atten 3. Сценарий `measurements/scripts/check_stage7_vst3.py` сравнил обе дорожки на протяжении 131072 сэмплов с автономным C++ DSP. Допуск для этой проверки — 1e−7 единицы амплитуды.

| Частота, Гц | Максимальная абсолютная разность | Заявленная хосту задержка, сэмплы |
|---:|---:|---:|
| 44100 | 4,65e−9 | 0 |
| 48000 | 7,43e−9 | 0 |
| 96000 | 5,22e−8 | 0 |

Release CTest этапа 6 повторён, 3/3. Предстоят pluginval, сохранение и восстановление сессии в отдельном тестовом REAPER, моно, автоматизация и смена блока/частоты в живом экземпляре. Панель A4 остаётся в работе.
