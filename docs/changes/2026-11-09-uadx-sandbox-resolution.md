# Восстановлена проверка процессинга UADx

Дата: 9 ноября 2026. Статус: причина неуспешных headless-проб локализована,
процессинг и повторяемость одной конфигурации проверены. Этап 3 ещё открыт.

## Решение

Прежние прозрачные UADx-рендеры выполнялись в ограниченном окружении.
Тот же Release `vst3render.exe`, тот же установленный VST3 и входной WAV
при разрешённом запуске вне sandbox успешно обработали сигнал. Внутренний
механизм ограничения (IPC, служба либо другой ресурс) отдельно не установлен.
Сообщение Please open UA Connect не было доказательством отсутствия установки
или лицензии. Переустановка и изменение лицензии не понадобились.

При попытке независимого запуска REAPER внутри sandbox Windows вернула
ошибку 623 Illegal System DLL Relocation до открытия проекта. Был подготовлен
отдельный пустой `eq_reaper_project/uadx-load-check.rpp`; аудиопроверка в REAPER
не выполнена. После успешного запуска существующего хоста вне sandbox
продолжена проверка этим хостом. Рабочие DAW-проекты не изменялись.

## Фактические результаты

44.1 kHz, stereo, block 512, impulse −18 dBFS, LF CPS 30, Boost 10,
остальные параметры по умолчанию, offline, `--require-latency=86`:

- API latency 86 samples; пик выходного импульса смещён на 86 samples.
- Выход отличается от входа, stereo difference peak 0.
- Повтор Boost=10 в новом процессе дал битово идентичные сэмплы и WAV SHA-256;
  repeat difference peak 0.
- Дополнительный flat-рендер также прошёл защиту latency=86.
- Диагностическое отношение FFT импульсов Boost/flat: 20 Hz +14.912 dB,
  30 Hz +13.527 dB, 60 Hz +9.788 dB, 100 Hz +6.534 dB, 1 kHz +0.130 dB.
  Это подтверждает действие параметра, но не является калиброванной АЧХ
  нелинейного плагина и не используется для подгонки DSP.

Артефакты: локальные `measurements/renders/calibration/pultec-unsandboxed*`;
сводка с SHA-256 — `measurements/results/activation_probe.json`.
Воспроизводимый анализ — `measurements/scripts/summarize_activation_probe.py`.
Запуски рендерера вне sandbox разрешены автоматической проверкой; исходники
плагина и системные настройки не изменялись. Коммитов и пушей не было.

## Следующий шаг и ограничения

Выполнять UADx-рендеры в разрешённом окружении вне sandbox, сохраняя защиту
по ожидаемой задержке отдельно для каждого SR. Совпадение latency само по
себе недостаточно: проверять действие параметров и сигнал.
Остаются калибровка известным фильтром, sweep/phase-анализ и паспорт опыта,
затем полная сетка. 86 samples подтверждены только при 44.1 kHz.
Субъективное качество, DAW-совместимость и модель Pultec не подтверждались.
DSP продукта не изменён, миграция/откат состояния не требуются.
