# Решение по этапу 6 после проверки прямой интерполяции

15 ноября 2026. Статус — этап открыт, серия локальных подгонок остановлена. Проверено одно заранее выбранное изменение при 44,1 кГц: кубическая RBF-поправка вычисляется непосредственно для дробных координат. Для каждой частоты использованы измеренные оси, Flat и 23 обучающие совместные настройки на CPS. Правило осевой интерполяции одинаково для обоих вариантов. На 97 уникальных ранее записанных дробных настройках выполнено парное сравнение.

Все четыре критерия выдержаны на 94/97 настройках при двухступенчатом расчёте и 96/97 при прямом. На CPS 60 / 0,5 / 10 ошибка по басу уменьшилась с 0,20828 до 0,19814 дБ. На CPS 100 / 2,25 / 9 прямой вариант дал максимумы 0,17509 / 0,15181 / 0,04758 дБ и 1,43731°. Превышен допуск 0,15 дБ в полосе 100–1000 Гц. У целых координат формулы совпадают; предыдущий тест по измеренным опорам дал 308/308.

Это ретроспективная диагностика комплексных спектров. Для причинного банка проверка v5 уже показала 0,35886 дБ и 2,73678° при CPS 60 / 0,5 / 10. Разница показывает, почему устранение одного оставшегося офлайн-превышения само по себе не закроет этап. Пока отсутствуют прошедшая аналитические допуски реализация для runtime, подтверждение golden-тестов этой модели на 44,1/48/96 кГц и проверка автоматизации.

Основание для остановки — исчерпан согласованный эксперимент, совместного прохода нет даже для прямого прогноза по точным опорам, а подбор по уже раскрытым настройкам не даст независимой проверки. При сохранении SPEC возобновление имеет смысл как отдельная задача по совместной подгонке причинной поверхности с проверками на исключённых обучающих узлах и новым резервом после заморозки. Изменение продуктовых допусков потребовало бы решения владельца.

Запуск из корня — `python measurements/scripts/check_pultec_direct_fractional.py`. [Попарные результаты](../../measurements/results/pultec_lf/causal_bank/direct_fractional_comparison.csv).
