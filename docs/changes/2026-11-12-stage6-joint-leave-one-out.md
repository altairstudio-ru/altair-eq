# Этап 6. Проверка интерполяции с исключением одного узла

12 ноября 2026. Офлайн-диагностика total_relative_v2, 44,1 кГц. В каждом из 92 прогнозов из интерполятора исключён проверяемый совместный узел. Сохранены 22 остальных узла того же CPS и обе измеренные оси. Прогноз сравнивался с фактическим комплексным откликом исключённого узла. Коэффициенты каждого исходного узла ранее подгонялись отдельно. Это внутренняя перекрёстная проверка при уже выбранной архитектуре.

|Метод|Прошли по CPS 20/30/60/100|Всего|Максимумы низ/середина/верх, дБ|Фаза, °|
|---|---|---:|---|---:|
|Прямая подгонка в известном узле|23/23/23/23|92/92|0,0473 / 0,0480 / 0,0485|1,3445|
|Интерполяция измеренных откликов|22/22/22/21|87/92|0,4645 / 0,3341 / 0,0792|3,5548|
|Интерполяция откликов банка v2|22/20/20/21|83/92|0,8252 / 0,4256 / 0,0960|5,3992|
|Нормированное взаимодействие по измерениям|22/22/22/21|87/92|0,3905 / 0,2129 / 0,1004|2,6583|
|Нормированное взаимодействие по банку|22/22/22/22|88/92|0,4699 / 0,2597 / 0,0924|3,1069|

Вторая форма делит комплексный остаток взаимодействия в положительных узлах на произведение Boost × Atten, интерполирует частное кубической RBF и восстанавливает множитель в целевой точке. Нулевое взаимодействие на осях следует из множителя. Проверялась только смена интерполяции, полюса и подогнанные отклики не менялись. Поскольку выход линеен по весам, линейная комбинация комплексных откликов банка соответствует той же комбинации весов его ветвей.

У нормированного банка все четыре промаха приходятся на Boost 2 / Atten 10. Исключение этого крайнего узла оставляет особенно редкую сетку рядом с ним. Даже интерполяция исходных измерений обычным алгоритмом ошибается здесь на всех CPS. Это локализует часть проблемы в форме интерполяции и расположении опор. Перекрёстная проверка не доказывает провал полной таблицы в самой точке 2/10, где измерение доступно.
