# Этап 6. Верхняя секция и дробные положения ручек

12 ноября 2026. Офлайн-проверка при 44,1 кГц. Базовая таблица — frozen_guard003_ridge0001_model.json. Рабочий DSP не изменялся.

## Верхний пик

Из 92 обучающих joint-настроек выбран максимальный пик исходного банка в 18–19,845 кГц. При CPS 20, Boost 10, Atten 6 он достигает +9,1204 дБ против +2,5978 дБ у референса на той же настройке. До 22,05 кГц расчётный пик исходной модели здесь +9,1205 дБ.

Проверена параллельная добавка одной фиксированной пары полюсов к исходному отклику. Центры 19–21 кГц с шагом 100 Гц, параметры экспоненциального затухания от 25 до 3200 Гц с удвоением, 168 вариантов. Оба вещественных выходных веса свободны. Линейная программа минимизирует нижнюю оценку пика по проекциям на направление исходного отклика. Внутри SPEC допустимый сектор комплексного отношения охвачен прямоугольником, поэтому полученный минимум оптимистичен. Даже лучшая нижняя граница +8,6125 дБ (19,3 кГц, затухание 100 Гц). Для отклонения этих вариантов достаточно одного обучающего узла. Вывод относится к фиксированным исходным весам и проверенным положениям полюса; совместная переподгонка всего банка остаётся отдельной гипотезой.

## Интерполяция управления

По сохранённым CSV измерений исследованы 272 уникальные дробные осевые настройки. При линейной интерполяции выходных весов прошла 231, при локальной кубической интерполяции Лагранжа по четырём целым узлам — 272. На краях используются ближайшие четыре доступных узла. Максимумы кубического варианта 0,10158 / 0,10061 / 0,09562 дБ в трёх полосах и 1,87290° по фазе. На каждом целом делении интерполяционные веса точно выбирают прежнюю строку; проверены все 11 значений каждой оси. Поэтому результаты ранее прошедших целых настроек сохраняются. Веса непрерывны на границах ячеек, полюса фиксированы. Переходы во времени при 20 мс сглаживания требуют отдельной проверки.

Кубический вариант проверен на той же коллекции после изучения результата линейного. Дробных измерений с одновременно активными ручками среди просмотренных записей нет. Следующая проверка управления — получить такие независимые измерения при подтверждённой задержке референса.

Дополнительная проверка flat по сохранённому WAV с проверкой SHA-256 показала пик модели +8,9044 дБ при 19 254,39 Гц уже с обеими ручками на нуле (CPS 20). Максимум референса в том же диапазоне +0,9083 дБ. Следовательно, для исследования пика достаточно сначала воспроизвести нейтральный тракт; изменение интерполяции регуляторов само по себе этот случай не исправит.
