# Запись: план работ Pultec LF MVP и этап 1 (baseline)

Дата: 8 ноября 2026.

Статусы (раздельно): план этапов 2–9 — предложено и утверждено пользователем, выполнение не начато; этап 1 — реализовано и проверено; `dump_fx_params.lua` — подготовлено, не проверено (запуск в REAPER на этапе 2).

## Назначение

Зафиксировать детальный поэтапный план работ по Pultec EQP-1A LF MVP в документах проекта и выполнить этап 1: воспроизводимый baseline, рабочая ветка, паспорт окружения.

## Затронутые файлы

- новый `docs/WORK_PLAN_PULTEC_MVP.md` — детальный план этапов 1–9, поздние ветки, риски, раскладка данных;
- `PLAN.md` — указатель на план; история решений 06–08.11 сохранена;
- `docs/STAGED_PLAN.md` — пометка «исторический, заменён WORK_PLAN_PULTEC_MVP.md»;
- новый `docs/BASELINE.md` — фактическое состояние сборки, тестов и окружения;
- новый `measurements/scripts/dump_fx_params.lua` — ReaScript-дамп параметров FX для паспорта эталона (этап 2);
- ветка git `pultec-lf-mvp` (без коммитов; коммит только по команде пользователя).

## Принятое решение и альтернативы

- План записан в документы проекта, а не только в чат: политика документирования (`docs/DOCUMENTATION_POLICY.md`) требует воспроизводимости и единого источника.
- Архитектура измерений (этап 3): основной вариант — ReaScript-оркестрация в отдельном экземпляре REAPER; fallback — `reaper -renderproject` батчем; fallback 2 — ручные рендеры по чек-листу. Окончательный выбор — после проверки поведения UADx в офлайн-рендере.
- Этап 1 выполнен без изменения DSP и `CMakeLists.txt`: baseline должен отражать исходное состояние до работ.
