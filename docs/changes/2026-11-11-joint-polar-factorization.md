# Этап 6: факторизация совместной поправки Boost/Atten

- Дата: 11 ноября 2026
- Статус: измерительный spectral fit найден; причинная realtime-модель пока не найдена.
- Назначение: понять, какая часть прежней ошибки связана с формой модели interaction residual, и проверить компактность измеренной поверхности.

## Измерения и анализ

Повторить четыре ранее проблемных reference sweep не удалось: UADx renderer завершился с latency 0, а скрипт с обязательным latency gate 86 samples отказался сохранять результат. Исходные измерительные WAV/CSV не менялись. Поэтому дальнейшие сравнения используют уже записанные -36 dBFS, 44,1 kHz sweep-наборы.

На измеренных одиночных осях Boost/Atten проверены три RBF-ядра для двух способов интерполяции joint-поправки. Интерполяция комплексной поправки сохранила high-band допуск почти на всей сетке; интерполяция только амплитуды в dB провалилась, например, на CPS 60 в 40/77 и на CPS 100 в 49/77 удержанных настройках. Полярное представление — логарифмическая амплитудная поправка плюс развёрнутая фаза — прошло установленные амплитудные и фазовые критерии на всех 308 holdout-комбинациях для каждого из трёх ядер.

Затем применена SVD отдельно к амплитудной и фазовой поверхностям каждого CPS. Одного спектрального режима с cubic-интерполяцией коэффициента достаточно, чтобы пройти проверенные критерии на всех 92 обучающих и 308 удержанных точках. Максимальная абсолютная ошибка амплитуды в 1–18 kHz на holdout для CPS 20/30/60/100: 0,0704/0,0519/0,0646/0,0746 dB; P90 по худшей ошибке на кривую: 0,0556/0,0433/0,0487/0,0546 dB. Максимальная фазовая ошибка: 0,397/0,414/0,507/0,459°. На обучающих узлах максимальная амплитудная ошибка: 0,0781/0,0448/0,0578/0,0881 dB; все ниже порога 0,10 dB.

Это компактная частотная модель измеренных откликов, но пока она использует готовые спектральные режимы и не является причинным realtime DSP. Шестисекционная SOS-подгонка multiplicative correction отдельно в каждом обучающем узле дала нормированную ошибку около 0,004–0,006, однако после RBF-интерполяции секционных ответов нарушила 1–18 kHz допуск в 73–77 из 77 случаев по CPS. Значит, узловой fit сам по себе не гарантирует удачное непрерывное поведение между настройками.

Проверен и rank-1 комплексный логарифмический режим: на всех CPS он прошёл обучающие и holdout-пороги для 1–18 kHz; максимальная holdout ошибка амплитуды составила 0,054–0,082 dB, фазы — 0,40–0,50°. Управляющий коэффициент после комплексного поворота почти вещественный (RMS мнимой части 5,4–8,5% RMS вещественной), но не строго вещественный. Попытка аппроксимировать экспоненту этого режима устойчивыми SOS (до 8 секций) не прошла: нарушено 33–59 из 77 holdout-кривых по CPS; максимум ошибки 0,161–0,206 dB. Лучшие fits использовали полюса почти на границе радиуса 0,999. Следовательно, rank-1 поверхность — хороший компактный офлайн-описатель измерений, но выбранная SOS-реализация режима пока непригодна.

## Артефакты и проверки

- `measurements/scripts/probe_pultec_lf_joint_magnitude_residual.py` — сравнение dB, комплексной и полярной интерполяции.
- `measurements/results/pultec_lf/joint_magnitude_residual_probe.json` — сводка по kernels/CPS.
- `measurements/scripts/probe_pultec_lf_joint_polar_svd.py` и `measurements/results/pultec_lf/joint_polar_svd_probe.json` — SVD-ранги и оценка обучающих/удержанных узлов.
- `measurements/scripts/fit_pultec_lf_joint_multiplicative_residual.py` и `measurements/results/pultec_lf/joint_multiplicative_sos_fits_6sec.json` — шестисекционная узловая проверка причинного фактора.
- `measurements/scripts/probe_pultec_lf_joint_multiplicative_sos.py` и `measurements/results/pultec_lf/joint_multiplicative_sos_probe.json` — независимый holdout-проход.
- `measurements/scripts/fit_pultec_lf_joint_polar_mode_sos.py` и `measurements/results/pultec_lf/joint_polar_mode_sos.json` — причинная SOS-попытка для единого логарифмического режима.
- Python-компиляция трёх новых probe/fit-скриптов прошла; `git diff --check` прошёл.
- Не проверялись realtime kernel, CPU, host automation, 48/96 kHz, DAW или качество звучания.

## Следующий шаг

Исследовать причинное представление одного измеренного комплексного логарифмического режима: оценить его гладкость/фазовую причинность и устойчивую rational/SOS-аппроксимацию, а затем интерполировать малое число управляющих коэффициентов, а не полные SOS-кривые. Повторные hardware/plugin renders выполнить, когда renderer снова сообщит согласованную latency 86 samples. Runtime DSP менять после прохождения обучающей и holdout-сеток.
