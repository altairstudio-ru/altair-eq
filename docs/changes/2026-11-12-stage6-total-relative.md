12 ноября 2026. Этап 6, исследовательская модель при 44,1 кГц и −36 dBFS. Статус: пройдены оси и обучение, контроль не пройден.

## До изменения
Поузловая реконструкция прежнего JSON сохранена в total_relative_before.csv до новой подгонки. Проверены порядок столбцов (48 FIR, 49 real, 49 imag), индексы CPS/Boost/Atten и равенство абсолютного отклика сумме осевой базы и взаимодействия. Максимальная комплексная невязка тождества 2,14e−13. Из 172 узлов прошли 75; замена только рассчитанного Flat измеренным в диагностике возвращает 172/172. В v1 оптимизировалась абсолютная разность с измеренным Flat вместо относительной ошибки полного реализованного выхода.

## Изменение и решение
Файл probe_pultec_total_relative.py использует фиксированные полюса и прежнюю строку Flat. Оптимизируются поправки к полным выходным весам осей и обучающих сочетаний. В матрице по каждой частоте отклик базиса делится на целевой комплексный transfer, правая часть равна единице за вычетом относительного отклика исходного узла. Критерий выбора итерации — худшее отношение четырёх ошибок итогового выхода к порогам SPEC. Штрафы учитывают измеренный верх и изменение рассчитанного хвоста. Для остальных целых настроек кубическая RBF интерполирует interaction с нулевыми опорами на осях. Для дробных настроек применяется прежняя четырёхточечная интерполяция Лагранжа по обеим ручкам. В целых узлах она точна, при подходе к узлу с любой стороны предел один. При нуле управление возвращает прежние веса Flat. Размер, устойчивость и оценка затрат соответствуют neutral_shared_pair_v1 (391 умножение/отсчёт на канал, 0 буферной задержки). Измерений CPU, 48/96 кГц и динамической автоматизации для v2 нет.

Модель total_relative_v2.json заморожена до резервных рендеров, SHA-256 f7e2b98e32b88f498ff1b86ebd66d9d172e6c3b9611e607faf3de4ff7bbddf57. Веса выбирались только по 80 осям и 92 joint train. Flat 4/4. Для нового резерва записаны все три заранее названные пары на каждом CPS через vst3render с обязательной задержкой 86; подтверждена в каждом отчёте. После записи всего набора проверены хеш модели, исходного sweep и всех 12 WAV по новому manifest.json. Однократный анализ SPEC дал 6/12. Ранее раскрытые 308 целых узлов использованы только для диагностики. После контроля веса не менялись.
