# Решение: Pultec EQP-1A как первый измерительный референс

## Уточнение версии — 8 ноября 2026

Пользователь сообщил предполагаемую версию **1.2.16**. Поиск по каталогам UA-плагинов сопоставляет номер 1.2.16 с **UADx Pultec EQP-1A EQ** (VST3/AU/AAX); это делает UADx наиболее вероятным форматом установленного экземпляра. До запуска измерений всё равно зафиксировать точное имя, формат и версию из DAW/менеджера UA: каталог не подтверждает состояние конкретной установки пользователя. Проверено по [каталогу плагинов](https://www.kvraudio.com/product/uadx-pultec-passive-eq-collection-by-universal-audio), найденному поиском 8 ноября 2026.

## Подтверждение коллекции пользователя — 8 ноября 2026

Пользователь предоставил страницу производителя [Pultec Passive EQ Collection](https://www.uaudio.com/products/pultec-passive-eq-collection) как коллекцию, которая у него установлена. Выбор EQP-1A как первого референса подтверждён. По странице UA в коллекцию входят EQP-1A, MEQ-5 и HLF-3C, доступны Native и Apollo/UAD-2 варианты.

Версия 1.2.16 ранее названа пользователем как вероятная и каталогом сопоставляется с **UADx Pultec EQP-1A EQ**. Это пока рабочая гипотеза о конкретной сборке: сама страница коллекции не показывает, какой вариант установлен/активен у пользователя. Перед измерениями записать имя, вариант (UADx или UAD-2), версию и формат из DAW либо UA Connect. Не помечать экземпляр как Legacy без подтверждения.

Страница UA используется как описание заявленных функций, а не как независимое доказательство совпадения эмуляции с физическим устройством. DSP и измерения пока не менялись/не выполнялись.

## Идентификация экземпляра по скриншоту REAPER — 8 ноября 2026

Скриншот пользователя показывает заголовок плагина: **VST3: UADx Pultec EQP-1A EQ (Universal Audio (UADx))**, размещённый на Track 2 «Bass» в REAPER v7.85. В меню плагина отображается **v1.2.16**. Это подтверждает для текущего рабочего экземпляра имя, формат VST3, вариант UADx и версию 1.2.16. Идентификация основана на видимом UI скриншота, предоставленного пользователем; отдельное чтение метаданных бинарника не выполнялось.

Следующий эксперимент можно планировать для этого конкретного экземпляра: зафиксировать состояние проекта/плагина и начать воспроизводимые замеры EQP-1A с отдельной LF Boost и Attenuation. Прежде чем считать что-либо результатом, записывать sample rate, буфер, параметры, уровень, bypass/EQ state и путь рендера. Сам скриншот идентифицирует плагин, но не является аудиоизмерением. На изображении видна открытая сессия REAPER «Разработка VST [modified]»; её не изменять без необходимости, а тестовый проект/копию использовать для стенда.
