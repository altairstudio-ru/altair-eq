# Этап 6: предварительная проверка модели по измеренным transfer-кривым

Дата: 10–11 ноября 2026. Статус: **подгонка исследована; гейт реализации DSP открыт**.

## Назначение

Проверить, может ли компактная устойчивая цифровая модель воспроизвести комплексный низкоуровневый
transfer UADx Pultec EQP-1A EQ v1.2.16 в пределах утверждённых требований из `docs/SPEC.md`.

## Что сделано

- Добавлена исследовательская подгонка каскада из четырёх устойчивых би-секций с ограничением радиуса
  полюсов, тремя стартовыми точками и продолжением от предыдущего решения на соседних значениях ручки.
- Скрипт подгонки: `measurements/scripts/fit_pultec_lf_stable_sos.py`.
- Подгонка выполнена по 152 кривым для 44,1/48/96 kHz из `lowlevel_analysis_manifest.json`.
- Записаны параметры и метрики в `measurements/results/pultec_lf/stable_sos_fits.json`.
- Выполнена проба шестисекционной модели на пяти точках с наибольшей ошибкой фазы.
- Выполнена отдельная проба трёх всепропускающих секций на восьми точках с наибольшей ошибкой фазы;
  скрипт `measurements/scripts/fit_pultec_lf_allpass_probe.py`, результат
  `measurements/results/pultec_lf/allpass_phase_probe.json`.
- Калибровочный RBJ-фильтр отрендерен через тот же renderer на идентичных −36 dBFS sweep-сигналах
  при всех трёх sample rate; сводка и SHA-256: `measurements/results/calibration/stage6-sweep-calibration.json`.
- Проверен повторный подбор с повышенным весом крайних частот на четырёх проблемных кривых;
  скрипт `measurements/scripts/fit_pultec_lf_edge_weight_probe.py`, результат
  `measurements/results/pultec_lf/edge_weight_probe.json`.

## Результаты

Исходная четырёхсекционная модель прошла все критерии одновременно на **72 из 152** узлов.
После подбора шести секций получен полный offline-fit с проходом по точечным метрикам на **152 из 152** узлов:

| Частота дискретизации | Прошло | Всего |
|---:|---:|---:|
| 44,1 kHz | 116 | 116 |
| 48 kHz | 18 | 18 |
| 96 kHz | 18 | 18 |

Максимальная ошибка по полосам для шестисекционной таблицы составила 0,197687 dB (20–100 Hz),
0,111758 dB (100–1000 Hz), 0,097993 dB (1000–18000 Hz); максимальная фазовая ошибка — 1,935225°.
Артефакт: `measurements/results/pultec_lf/stable_sos_six_section_fits.json`.

Это подтверждает только точечную численную подгонку measured nodes. 129 из 152 решений имеют радиус
полюса не ниже 0,99989; максимальный радиус — 0,9999. Теоретическая проверка перевода коэффициентов
секций в float32 дала 15 секций с вычисленным радиусом корней не ниже 1 (максимум около 1,000164).
В исходном `dsp/SourceEq.h` используется double, однако новый компонент ещё не спроектирован и данная
проверка не заменяет тестов его реализации.

Полный пересчёт с ограничением радиуса 0,999 завершён после исправления возобновления: все 152 узла
пересчитаны или сохранены только при проверенном ограничении, и **152/152 проходят**. По sample rate:
44,1 kHz — 116/116; 48 kHz — 18/18; 96 kHz — 18/18. Максимальная ошибка по полосам — 0,068148 dB,
0,053863 dB и 0,089154 dB; максимальная фазовая ошибка — 1,813746°. Артефакт:
`measurements/results/pultec_lf/stable_sos_six_section_fits_r0999.json`.
Повторная подгонка последнего проблемного узла запускается через
`measurements/scripts/fit_pultec_lf_single_node_probe.py`, результат —
`measurements/results/pultec_lf/single_node_cap_probe.json`.

Для 10 узлов с худшими ошибками cap-run сначала прошёл локальную пробу 10/10. Один узел 48 kHz,
который не прошёл первоначальную полную подгонку при лимите 0,999, был повторно запущен с warm start
из шестисекционной модели без ограничения: он прошёл с ошибками 0,005648 dB / 0,006705 dB /
0,059994 dB и 1,021581°. Итоговая ограниченная таблица после этого тоже проходит 152/152.

Теоретический перевод знаменателей SOS в float32 с последующим расчётом корней дал 0/912 секций
с радиусом ≥1; максимальный радиус — 0,999246. Это улучшает запас относительно исходной модели,
но пока не является тестом реализации DSP и её внутреннего состояния.

Проверка переноса одной модели с 44,1 kHz на другие частоты дала 0/36 проходов при простом масштабировании
корней и 25/36 при билинейном отображении с перенастройкой gain (18/18 на 48 kHz, 7/18 на 96 kHz).
Следовательно, для каждого sample rate пока нужны отдельные измеренные модели либо отдельный проверенный
метод преобразования.

Четыре секции ранее прошли критерии АЧХ по каждой из трёх полос и фазы одновременно на **72 из 152** узлов:

| Частота дискретизации | Прошло | Всего |
|---:|---:|---:|
| 44,1 kHz | 47 | 116 |
| 48 kHz | 8 | 18 |
| 96 kHz | 17 | 18 |

Ни на одном узле ошибка АЧХ в полосах 20–100 Hz и 100–1000 Hz не превысила лимит. Лимит верхней полосы
1–18 kHz превышен на 48 узлах; предел ошибки фазы 2° превышен на 51 узле. Эти множества пересекаются.
Полюса подогнанных фильтров оставались внутри единичного круга, однако все максимальные радиусы достигли
границы 0,9999. Это не доказывает достаточный запас устойчивости для параметрической интерполяции.

Шестисекционная проба прошла оба допуска только на одной из пяти проверенных сложных точек. Повышение
порядка само по себе проблему не решило; результаты записаны в
`measurements/results/pultec_lf/stable_sos_six_section_probe.json`. Проба дополнительных allpass-секций
также не снизила фазовую ошибку до 2° ни на одной из восьми выбранных точек. Максимум фазовой ошибки у всех
51 четырёхсекционной точки, не прошедшей фазовый предел, находится на краю проверяемого диапазона:
у 28 точек — на 20 Hz, у 23 — на 18 kHz. Это указывает на необходимость отдельно исследовать границы
измерения и фазовую модель.

Повышенный вес частот около границ (×2/×4/×8) исправил одну из четырёх пробных кривых; на остальных
уменьшение фазовой ошибки сопровождалось ростом ошибки АЧХ и прохода полного критерия не дало. Поэтому
одной перенастройкой весов подгонки весь набор пока не закрыть.

Повторная калибровка измерительного тракта выполнена тем же тестовым RBJ 1 kHz / +6 dB / Q=1 и теми же
входами сетки LF. На 44,1 kHz максимальное расхождение составило 0,00000198 dB / 0,0000127°; на 48 kHz —
0,00000195 dB / 0,0000134°; на 96 kHz — 0,00000140 dB / 0,0000106°. Все три результата проходят
калибровочные пределы 0,05 dB / 1° в диапазоне 20–18 kHz; сообщённая renderer задержка — 0.

Входной спектр в точках 20 и 18 kHz находится соответственно примерно на 12 и 41 dB ниже своего максимума,
то есть заметно выше применённого анализатором порога энергии −80 dB. Для одной сложной конфигурации
необработанная transfer-кривая была плавной рядом с 20 Hz и 18 kHz; резкого скачка на границах не обнаружено.
Сигналы имеют шаг FFT 1/17,5 Hz, при котором обе контрольные частоты попадают точно в бин. Это снимает
подозрение на низкую энергию либо ошибку интерполяции этих двух бинов, но не задаёт полной неопределённости
измерения Pultec.

## Решение и альтернативы

**Решение:** точечный критерий offline-fit закрыт для шести секций при ограничении радиуса 0,999.
Гейт переноса в DSP остаётся открыт до проверки интерполяции между значениями ручек и реализации
коэффициентов/состояния в C++ и golden-тестах.

Рассматривались четыре и шесть би-секций. Шесть секций проходят sampled-node fit с r≤0,999 на всех
частотах дискретизации. Проверка переноса между sample rate и интерполяции параметров всё ещё открыта.
Послабление критериев или исключение узлов не утверждалось; значения SPEC сохранены.

## Проверки и ограничения

- Выполнен численный Python-подбор на sweep transfer-данных и независимая калибровка измерительного тракта
  известным фильтром; калибровка не проверяет DSP AltaiR EQ.
- C++/CTest, сборка, VST3-рендер, автоматизация параметров, DAW и прослушивание не выполнялись.
- Подгонка проверяет только измеренные узлы; интерполяция между ними, гладкость автоматизации и Output
  Trim ещё не реализованы и не проверялись.
- Результат не подтверждает качество звучания или эмуляцию конкретной аналоговой схемы.
- Раннее грубое предположение о фазовой ошибке из минимально-фазового cepstrum не используется как
  вывод: чувствительность продолжения спектра за измеренными 20 Hz–18 kHz не проверена достаточно.

## Следующий шаг

Следующий шаг — определить и проверить параметрическую интерполяцию шести SOS между измеренными точками
ручек для каждого sample rate. После этого реализовать DSP и golden-тесты; перед пользовательскими
DAW-измерениями остановиться, чтобы пользователь мог присутствовать.
