# Приёмка DSP-компонента LF MVP

16 ноября 2026. Этап 6 закрыт с пятью [утверждёнными исключениями](2026-11-16-stage6-mvp-exceptions-proposal.md). Следующий этап — оболочка VST3.

В `dsp/FrozenLfBank.h` реализован независимый C++17-компонент. Экспортёр проверяет хеши замороженных коэффициентов и заранее пересчитывает таблицы отдельно для каждой частоты дискретизации. В аудиопотоке обработчик использует фиксированные массивы, причинные FIR и 49 устойчивых комплексных полюсов с независимой историей каждого канала. Выход текущего отсчёта доступен сразу. Веса, EQ In и Output Trim меняются за 20 мс; при новой цели переход начинается с текущего значения. При обходе хостом возвращается входной отсчёт, банк продолжает обновлять историю.

Release собран под Windows x64. CTest — 3/3. Временные golden-векторы получены независимым смешиванием откликов статических ветвей; проверено прерывание перехода, моно, отсутствие сигнала в молчащем правом канале, Output Trim, EQ In и прозрачный обход. Отдельно из собранного процессора сняты импульсы для каждой измеренной комбинации и сопоставлены с комплексными кривыми UADx.

[Отчёт по каждой кривой](../../measurements/results/pultec_lf/causal_bank/frozen_cpp_acceptance.csv). Данные включают обучение, ранее раскрытые проверки и независимый резерв. За верхней границей SPEC остаётся диагностическое отклонение +1,84 дБ около 20,41 кГц на одной настройке при 96 кГц. Проверка относится к низкоуровневому линейному режиму и отдельному DSP. Тестирование VST3 в DAW относится к следующим этапам.

Из корня: `cmake -S . -B build/stage6`, `cmake --build build/stage6 --config Release`, `ctest --test-dir build/stage6 -C Release --output-on-failure`, `python measurements/scripts/accept_frozen_cpp.py`. Для повторного экспорта таблиц и временных эталонов — `python measurements/scripts/export_frozen_bank_cpp.py`. Шестисекционный прототип сохранён отдельно.
