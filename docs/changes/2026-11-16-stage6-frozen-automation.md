# Сглаживание замороженного банка при автоматизации

16 ноября 2026. Перед проверкой сверены хеши из независимого резерва CPS 20/60. Для банка с фиксированными полюсами испытана линейная рампа выходных весов длительностью 20 мс. Состояния фильтра продолжают обрабатывать сигнал при смене цели. Общие выходная и добавочная FIR на 48/96 кГц учтены в обоих путях.

На двухтоновом моносигнале 43 и 1350 Гц выполнены четыре переключения CPS/Boost/Atten, одно через 5 мс после предыдущего. Поотсчётный выход сверен с параллельным расчётом статических ветвей и их плавным смешиванием до общей FIR.

| SR | Длина рампы, отсчёты | Макс. абсолютное расхождение |
|---|---:|---:|
| 44,1 кГц | 882 | 2,08e−13 |
| 48 кГц | 960 | 1,67e−13 |
| 96 кГц | 1920 | 3,75e−13 |

Это численная проверка принципа сглаживания в float64 при заданных событиях. Для производственного гейта ещё требуются утверждённая статическая модель, проверка её реального C++-обработчика, стереоканалов и обхода, а также тесты автоматизации в этом обработчике. Пять известных статических отклонений требуют исправления либо решения владельца по исключениям. Запуск — `python measurements/scripts/check_frozen_bank_ramps.py`.
