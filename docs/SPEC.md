# AltaiR EQ — спецификация LF MVP

Дата: 10 ноября 2026. Статус: **УТВЕРЖДЕНА ПОЛЬЗОВАТЕЛЕМ; основание для этапа 6**.
Основа: измерения UADx Pultec EQP-1A EQ VST3 v1.2.16 из [`RESULTS_PULTEC_LF.md`](RESULTS_PULTEC_LF.md),
дамп параметров `measurements/passports/vst3_dump_pultec_eqp1a.json` и визуальное направление A4,
утверждённое пользователем.

Пользователь утвердил этот черновик 10 ноября 2026. Предложенные численные критерии, состав функций и
рабочие условия теперь являются требованиями MVP. Измеренные факты и ограничения по-прежнему отделены
от продуктовых требований.

## 1. Область первого выпуска

Создать модуль AltaiR EQ для низкочастотной секции в виде переиспользуемого DSP-компонента и отдельного
плагина VST3. Первый выпуск охватывает только низкочастотные параметры выбранного референса. Он не
заявляет восстановление схемы по компонентам, точную эмуляцию аналогового устройства или подтверждённое
качество звучания.

**Утверждённая модель MVP:** воспроизводить измеренное поведение АЧХ и фазы на малом уровне сигнала с помощью
линейного DSP с нулевой задержкой. В измерениях CPS 60 / Boost 6 / Atten 4 кривая на sweep при −24 dBFS
отличалась от кривой при −36 dBFS максимум на 0,026948 dB / 0,199748°, а при −12 dBFS — максимум на
0,181066 dB / 1,794594°. Это ограниченные данные для одной ненулевой настройки. Эмуляция нелинейного
характера в MVP не входит, если пользователь отдельно не утвердит дополнительный этап измерений и модели.

## 2. Подтверждённые свойства референса

| Контроль или поведение | Измеренные свойства референса | Источник / статус |
|---|---|---|
| LF Frequency | 20 / 30 / 60 / 100 CPS; значение по умолчанию — 30 | Дамп параметров и полная сетка sweep |
| LF Boost | Непрерывно 0,00–10,00; по умолчанию 0 | Проверка параметров и сетка рендеров |
| LF Atten | Непрерывно 0,00–10,00; по умолчанию 0 | Проверка параметров и сетка рендеров |
| EQ Enable | In / Out; по умолчанию In | Дамп параметров и рендеры служебных состояний |
| Output | −12,0…+12,0 dB, шаг 0,1; по умолчанию 0,0 dB | Дамп и пять измерений Output Gain |
| Output OFF | В референсе есть отдельное состояние OFF | Дамп подтверждает наличие; поведение звука в OFF не измерено |
| Power / Master Bypass | Отдельные органы управления референса | Дамп и служебные рендеры; отображение в AltaiR — решение продукта |
| Измеренная задержка | 86 сэмплов при 44,1 и 48 кГц; 118 при 96 кГц | Контроль задержки renderer и калибровочные записи |

Измеренный референс — экземпляр UADx Pultec EQP-1A EQ. Его интерфейс, нормализация параметров, задержка
и внешний вид оборудования не являются обязательными деталями реализации AltaiR EQ.

## 3. Утверждённые параметры MVP

| Параметр AltaiR | Тип / диапазон | Значение по умолчанию | Утверждённое решение |
|---|---|---:|---|
| LF Frequency | Выбор одного из значений: 20, 30, 60, 100 Hz | 30 Hz | Включить; дискретный переключатель |
| LF Boost | Непрерывно 0,00–10,00 | 0,00 | Включить; показывать две цифры после запятой |
| LF Attenuation | Непрерывно 0,00–10,00 | 0,00 | Включить; показывать две цифры после запятой |
| EQ In | Вкл. / выкл. | Вкл. | Включить; отделить от обхода плагина в хосте |
| Output Trim | Непрерывно −12…+12 dB, шаг/отображение 0,1 dB | 0,0 dB | Включить в MVP |
| Состояние Output OFF | Отдельный режим | Выкл. | Отложить до измерения поведения и согласования смысла для пользователя |

Частота дискретна, потому что референс предлагает только четыре позиции CPS. Boost и Attenuation остаются
непрерывными: округление до целых изменило бы подтверждённый диапазон управления референса. Банки A/B,
COPY, RESET, пресеты, анализатор, HF-секция, MEQ-5 и HLF-3C в это предложение MVP не входят.

## 4. Утверждённые критерии точности DSP

Критерии утверждены пользователем 10 ноября 2026. Сравнивать DSP
с низкоуровневыми sweep-данными референса при −36 dBFS, компенсируя задержку референса в офлайн-анализе.
Импульс с пиком 0 dBFS не использовать как эталон АЧХ.

| Частотная область | Максимальная абсолютная ошибка АЧХ |
|---|---:|
| 20 Hz ≤ f < 100 Hz | 0,20 dB |
| 100 Hz ≤ f < 1 kHz | 0,15 dB |
| 1 kHz ≤ f ≤ 18 kHz | 0,10 dB |

Предел ошибки фазы: не более 2° по модулю с приведением к диапазону −180…+180° от 20 Hz до 18 kHz.
Ошибка Output Trim — не более 0,05 dB относительно заданного усиления. Это требования к продукту, а не
результаты измерений референса.

## 5. Работа в реальном времени и в хосте

- Частоты дискретизации: 44,1, 48 и 96 kHz.
- Обработка моно и стерео; стереоканалы обрабатываются независимо. Связь между каналами не входит в EQ.
- Целевая задержка — 0 сэмплов. Это осознанно отличается от задержки измеренного референса; при офлайн-
  сравнении задержка референса компенсируется.
- Изменение параметров не должно вызывать щелчки. **Утверждённое** время сглаживания — 20 ms, как
  начальное значение из существующего прототипа AltaiR EQ. Это значение не измерено у референса.
- EQ In управляет состоянием эквалайзера. Обход плагина, которым управляет хост, остаётся отдельным
  состоянием и должен отдельно отражаться в тестах.
- В аудиопотоке запрещены выделение памяти, блокирующие блокировки и файловый ввод-вывод.
- Параметры должны сохраняться и восстанавливаться хостом; для VST3-оболочки нужны стабильные ID.

## 6. Направление интерфейса

Использовать утверждённый визуальный вариант **A4 — рэковый модуль** из `design/lf-mvp/mockup-a4-rack.html`
и `design/lf-mvp/05-variant-rack.md`: объёмные ручки, четырёхпозиционный регулятор LF Frequency, лицевая
панель рэкового модуля и физический переключатель EQ In. Output Trim входит в MVP; A/B, COPY и RESET не
должны попасть в продукт только потому, что видны на концепт-макете. Интерфейс должен отличать EQ In от
обхода плагина в хосте.

## 7. За пределами MVP и ограничения заявлений

- В первом LF MVP нет HF-секции, MEQ-5, HLF-3C, пресетов, анализатора, модели нелинейного характера,
  режима oversampling или интеграции с Mix Studio.
- Не заявлять точное восстановление аналоговой схемы, эмуляцию конкретного оборудования или субъективное
  качество звучания.
- Совпадение низкоуровневой АЧХ не обещает воспроизведение уровневых искажений или поведения референса
  при высоких уровнях сигнала.
- Состояние Output OFF не реализовывать до измерения его поведения и согласования пользовательского смысла.

## 8. Решения пользователя

10 ноября 2026 пользователь утвердил параметры и состав LF MVP, включая Output Trim; частоты 44,1/48/96
kHz; моно/стерео; нулевую задержку; сглаживание 20 ms; приведённые допуски АЧХ, фазы и Output Trim.
Утверждён также линейный малосигнальный охват первого MVP. Нелинейный характер и состояние Output OFF
отложены. Это решения о продукте; они не означают, что реализация уже соответствует допускам.

Утверждение SPEC разрешило этап 6 — проектирование и реализацию DSP с golden-тестами по измеренным
данным. Архитектурные решения должны следовать этим требованиям; новые продуктовые режимы нельзя добавлять
без отдельного согласования.
