# AltaiR EQ LF 0.1.3 — локальная альфа

В REAPER добавьте эффект **VST3: AltaiR EQ LF** на дорожку. В этой версии доступны выбор частоты 20, 30, 60 или 100 Гц, усиление Boost, ослабление Attenuation и выходной уровень Output Trim. EQ In включает обработку секцией эквалайзера.

## Стартовые настройки

| Задача | Частота | Boost | Attenuation |
|---|---:|---:|---:|
| Нейтральная отправная точка | 30 Гц | 0 | 0 |
| Мягко прибавить низ басу — рекомендуемая настройка | 60 Гц | 2 | 0 |
| Сравнить с настройкой из прослушивания | 60 Гц | 7 | 3 |

Начните с Output Trim 0 дБ и подстройте его для сравнения при одинаковой громкости. Эти настройки можно сохранить через меню пресетов REAPER.

## Установка и откат

Сохраните проекты и закройте REAPER. Перед заменой сохраните копию всего установленного пакета `AltaiR EQ LF.vst3` вне каталога сканирования VST3. Для отката закройте REAPER, восстановите весь предыдущий пакет по прежнему пути и снова откройте программу.
