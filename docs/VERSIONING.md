# Версии AltaiR EQ

Номер релиза задаётся в `CMakeLists.txt`. Сборка передаёт его в метаданные VST3 и на шильдик редактора. Номер меняется один раз при подготовке релиза. Если в релиз входит несколько изменений, выбирайте самое существенное для пользователя.

| Что вошло в релиз | Команда | Пример для 0.1.4 |
|---|---|---|
| Исправление, косметика, упаковка | `python tools/bump_version.py fix` | 0.1.5 |
| Новая возможность для пользователя | `python tools/bump_version.py feature` | 0.2.0 |
| Несовместимость с проектами, пресетами или автоматизацией | `python tools/bump_version.py breaking` | 0.2.0 |
| Первый стабильный выпуск по отдельному решению | `python tools/bump_version.py stable` | 1.0.0 |

Команда показывает следующий номер. Добавьте `--apply`, чтобы записать его. После 1.0.0 несовместимые изменения повышают первую цифру. Масштаб внутренней переработки сам по себе не повышает её.

## План первого стабильного выпуска

После завершения запланированного цикла разработки выпускаем `1.0.0-beta.1`. Пользователь пробует бета-версию в рабочих проектах около двух недель. По итогам обратной связи исправляем выявленные проблемы и выпускаем `1.0.0` как первый стабильный выпуск.

Текущая команда меняет числовую версию. Перед выпуском беты нужно добавить поддержку суффикса в обозначении выпуска, чтобы бета и стабильная версия различались в пакете и интерфейсе.
