# Состояние AltaiR EQ LF

Первый прототип VST3 использует код производителя `Altr` и код плагина `AeLf`. Хост получает состояние в бинарном XML-формате JUCE. Корневой ValueTree называется `AltairEqLF`, атрибут `version` равен 1. Процессор восстанавливает значения через AudioProcessorValueTreeState при совпадении имени и версии. Историю фильтра и положение рампы он рассчитывает при обработке.

| ID параметра JUCE | Значение | По умолчанию |
|---|---|---|
| lfFrequency | Индекс 0–3 для 20, 30, 60, 100 CPS | 1 (30 CPS) |
| lfBoost | 0–10 | 0 |
| lfAtten | 0–10 | 0 |
| eqIn | Булев | Вкл. |
| outputTrim | −12…+12 дБ с шагом 0,1 дБ | 0 дБ |
| bypass | Булев, параметр обхода хоста | Выкл. |

Версионная подсказка JUCE для всех шести параметров равна 1. Изменение идентификаторов потребует проверки совместимости с автоматизацией сохранённых сессий.
