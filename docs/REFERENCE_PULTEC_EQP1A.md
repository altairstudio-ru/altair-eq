## 5. Классификация фактов

### Подтверждено первичным источником
- Экземпляр: UADx Pultec EQP-1A EQ, VST3, v1.2.16 — скриншот + прямое чтение `version_string`.
- LF CPS 20/30/60/100 — дамп (тексты ступеней) + фрагмент мануала UA (поиск 08.11.2026).
- LF Boost / LF Atten: непрерывные 0.00–10.00, линейный закон по normalized — дамп (probe 1001 точка).
- Наличие Enable (EQ IN, default In), Output (OFF, −12…+12 dB, default 0.0), Power, Master Bypass — дамп.
- Задержка API 86 samples @44100 — дамп.

### Требует первичной проверки
- Полный текст мануала UA (страница агенту недоступна: fetch failed/403): заявленные режимы, отличия UADx от UAD-2, oversampling.
- Способность экземпляра обрабатывать сигнал в офлайне (инициализация успешна, процессинг не проверялся).

### Только измерением
- Реальная АЧХ и фаза; форма boost и atten shelf.
- Взаимодействие одновременных Boost+Attenuation на одном CPS («low-end trick»).
- Уровневая зависимость и гармоники (окраска тракта/makeup-усилителя).
- Зависимость от sample rate; измеренная задержка.

## 6. Чек-лист этапа 2 и его статус

1. Копия проекта + UADx + дамп в REAPER — **заменено** headless-дампом 09.11.2026; REAPER-кроссчек опционален (`dump_fx_params.lua` готов).
2. Запуск дампа — выполнен headless (`tools/vst3paramdump`).
3. Лицензия в UA Connect — **частично**: инициализация успешна без запущенного UA Connect; процессинг подтвердить первым рендером.
4. Выдержка мануала EQP-1A — **открыто**: страница UA агенту недоступна, ждёт пользователя.
