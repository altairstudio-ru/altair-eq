# 05 — Вариант A4 «Лицевая панель rack-модуля» (hardware-стайлинг, физический тумблер EQ IN)

Дата: 10 ноября 2026. Статус: **ВИЗУАЛЬНОЕ НАПРАВЛЕНИЕ УТВЕРЖДЕНО ПОЛЬЗОВАТЕЛЕМ**; функциональные предложения и реализация UI отдельно не утверждены.
База: вариант A3 (`mockup-a3-freq-knob.html` / `.png`, запись `04-variant-freq-knob.md`), который в свою очередь
переиспользует объёмный язык A2 (`03-variant-volumetric.md`) и спеку A (`02-ui-spec.md`). Запрос пользователя:
подать панель как **отдельный модуль рэковой стойки** с «физическим» переключателем ON/OFF. Baseline-файлы
(`mockup.*`, `mockup-a2-*`, `mockup-a3-*`, `01/02/03/04-*.md`, `concept-b.*`) не изменялись.

**Важно о смысле стиля:** hardware-подача — это **стиль модуля, а не утверждение о звуке**. Рэковая эстетика,
металл, винты и тумблер не заявляют эмуляцию какого-либо железа, точность тракта или подтверждённое качество
звучания. Контент-контракт A2/A3 (§2 спеки) не изменился.

## Композиция и размеры

- Окно **960×460** (у baseline/A2/A3 — 960×340). Модуль сознательно **выше на 120 px** — осознанный trade-off:
  высота нужна под вертикальный ход рычага тумблера (гнездо-безель 56×108 + подписи ON/OFF) и под поля
  пластины (винты, кромки). Ширина 960 сохранена, чтобы колонки ручек остались в геометрии A2/A3.
- Окно = сцена (тёмный фон стойки) + **модуль**: левое ухо 16 px + лицевая пластина 904 px + правое ухо 16 px,
  высота 432 px, поля сцены 12–14 px, у модуля мягкая внешняя тень.
- Зоны пластины: **шапка-полоса** 54 px (шильдик «AltaiR EQ», чип «LF MVP», канавка, гравировка
  «LOW-FREQUENCY SECTION»; справа — чип PROPOSAL и hardware-клавиши A/B/COPY/RESET) →
  **основной ряд** (колонки: LF FREQUENCY 168, BOOST 204, ATTENUATION 204, OUTPUT TRIM 150,
  **EQ IN-тумблер 90**, между ними канавки-сепараторы 14 px) → **служебная полоса** (утопленный паз 52 px:
  подсказки жестов слева, справа гравировки «LF-1 · REV A» и «DESIGN PROPOSAL v0.1»).
- Крепёж: **4 винта по углам пластины** (⌀12, inset 6 px) + **по 2 монтажных винта в ушах** (⌀16 в отверстиях);
  всё — SVG-символы (дюмель с крестом шлица, радиальный градиент, верхний рим-блик, световая губка креста,
  drop-shadow), без внешних картинок.
- Подсказки жестов перенесены в служебную полосу (как разрешено ТЗ); resize-глиф из подвала A3 **убран**
  (окно подано как физический модуль; правила масштабирования §8 спеки не пересматривались).

## Тумблер EQ IN — «физический» переключатель

- **Семантика: EQ IN (section enable) — подтверждённый параметр эталона (§2 спеки), НЕ host bypass.**
  Соответствие host-bypass — отдельная тема (§4, решение требует проверки на этапе 7) этим контролом
  не решается и в макете не заявляется. На пластине под тумблером — гравировка **«NOT HOST BYPASS»**
  (в полосе подписей SCALE); в ARIA-метке то же уточнение.
- **Положения:** рычаг **вверх = ON**, **вниз = OFF** — два явных положения, промежуточного хода нет.
  Гравированные подписи ON (над гнездом) и OFF (под гнездом): активная позиция — #DDE1E6 / 700,
  неактивная — #7C838C / 400. **Состояние читается положением рычага + подписью, не только цветом**;
  LED ⌀8 в обойме — вторичный признак: ON — заполненный зелёный со свечением (ok #79C267), OFF — полый
  тёмный с ободком (правило §4 «не только цветом» сохранено и усилено механикой рычага).
- **Поведение (PROPOSAL, в макете не исполняется):** click по тумблеру переключает; на фокусе — Space/Enter;
  focus-ring 2 px #8AB4F8; переключение — обычный parameter change. При OFF контролы остаются
  редактируемыми и **не диммируются** (§4) — кадр OFF это показывает: вся панель идентична, меняется только
  узел тумблера.
- **Два кадра в одном файле:** `#off` добавляет класс `.is-off` (положение рычага, акцент подписи, LED).
  Скрипт-переключатель — **только рендер-помощник** для снимка OFF; интерактивом это не является.

## Что переиспользовано от A2/A3 (1:1)

- **Ручки:** вся SVG-геометрия и объёмная трактовка A2/A3 без изменений — частота 150×136 (тело r36,
  дуга r44, детент-тики r46–54, подписи на r64, указатель r21→r31), Boost/Atten 156×136 (r42/r50),
  Trim 112×136 (r30/r38); те же градиенты тела/шляпки, фаска с rim-light, спекуляр, нижняя внутренняя
  тень, drop-shadow, объёмный указатель (тёмный подложечный штрих + акцент).
- **Детенты частоты:** 4 позиции по 90° на 270° sweep, показано 60 Hz, активный тик 2.5 #DDE1E6,
  акцент позиции — токен select-bar; промежуточных тиков нет.
- **Значения:** 60 Hz / 6.40 / 4.20 / +0.0 dB; readout-поля 92×30 и 96×30 (фон #101216, Cascadia Mono);
  подписи DEFAULT: 30 Hz, SCALE 0–10, −12 … +12 dB.
- **Контент-контракт:** Boost/Atten — безразмерные **0–10 (не dB)**; частота **только 20/30/60/100**;
  Output Trim и A/B/COPY/RESET — **PROPOSAL** (чипы сохранены); никакого HF, пресетов, графика АЧХ,
  неподтверждённых режимов.
- **Типографика:** Bahnschrift + Cascadia Mono, размеры/веса/трекинг §6; структура шапки A3
  (бренд · чип · caption · PROPOSAL · A/B · COPY · RESET) сохранена, элементы перелицованы под hardware.
- **ARIA/фокус:** роли slider/textbox/radiogroup из A3; тумблер — `role="switch"` + `aria-checked`
  (ON-кадр true, OFF-кадр false через рендер-помощник); focus-visible правила §4 сохранены.

## Отличия от спеки A (документируются явно, при утверждении вносятся в спеку)

1. Окно 960×340 → **960×460**; добавлены сцена, уши, поля пластины (см. выше).
2. Шапка и подвал baseline заменены hardware-полосами: шапка — клавиши, подвал — утопленный служебный паз;
   resize-глиф убран.
3. **EQ IN перемещён из шапки в правую колонку основного ряда** и заменён с LED-кнопки на рычажный тумблер;
   добавлена подпись NOT HOST BYPASS.
4. EQ IN off: вместо «фон/граница поверхности» (§4) — механика рычага + подсветка подписи позиции + полый LED;
   правило «не только цветом» усилено.
5. Групповые подписи **центрированы** над колонками (в A3 LF FREQUENCY/OUTPUT TRIM были слева) — симметрия
   гравировки по колонкам.
6. Сепараторы-линии стали **канавками** (тёмная борозда + световая губка).
7. §7 «внешних drop-shadow нет» — расширено исключение A2: тень модуля на сцене, тени винтов/клавиш/шильдика/
   гнезда тумблера/LED-обоймы. Все тени мягкие, служат материальности.
8. Новые материальные тона (таблица выше) — дополнение к §5, только для hardware-варианта.
9. Декоративная гравировка «LF-1 · REV A» на служебной полосе — художественная деталь подачи, не заявляет
   модель/ревизию продукта.

## Статусы

- **Предложено:** вся hardware-трактовка (пластина, уши, винты, гравировка, зерно, клавиши, служебный паз),
  физический тумблер EQ IN с семантикой «EQ IN ≠ host bypass», его поведение (click/Space/Enter), кадр OFF,
  новые материальные тона, отличия 1–9.
- **Реализовано в макете:** статическая композиция `mockup-a4-rack.html` (кадр ON) и OFF-кадр по `#off`.
  Поведение (drag, клавиатура, entry, переключение тумблера) **не исполняется** — как в baseline/A2/A3.
- **Проверено:** оба PNG отрендерены headless Chrome (960×460, scale factor 1) и **просмотрены глазами**:
  полные кадры ON и OFF плюс увеличенные кропы — тумблер ON, тумблер OFF, верх-лево (ухо/винт/шильдик),
  верх-право (винты/клавиши), низ-лево (винт/служебный паз), зона Trim/фактура. Тумблер читается в обоих
  положениях (рычаг + подпись + LED); в OFF остальная панель идентична ON (нет dimming). По результатам
  первого просмотра исправлены два дефекта и сделан повторный рендер: винт уха выступал за фланец (уменьшен
  до ⌀16), зерно порошковой окраски не читалось (альфа поднята до 0.10/0.7). Винты/уши читаются объёмно
  (градиент + рим-блик + тень), подписи не перекрыты, переносов строк нет.
- **Не проверялось и не заявляется:** звук, DSP, АЧХ/фаза, эмуляция какого-либо железа, работа в DAW,
  поведение контролов, host-bypass, отображение при других масштабах/HiDPI, реализация в JUCE.
  Hardware-стиль не является утверждением о тракте или качестве звучания.
