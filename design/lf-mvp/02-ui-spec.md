## 4. Состояния и взаимодействия (PROPOSAL к реализации)

Общие правила:
- **Drag по вертикали** на ручке: вверх = увеличение. Чувствительность: Boost/Atten — полный диапазон 0–10
  за 200 px (0.05/px); Trim — 24 dB за 240 px (0.1 dB/px). **Shift+drag** = fine, коэффициент ×0.1
  (0.005/px и 0.01 dB/px). Курсор `ns-resize`; во время drag readout подсвечен границей #454C58.
- **Double-click** по ручке или readout = сброс к default параметра (Boost/Atten 0, Trim 0.0 dB).
  Double-click по кнопке частоты не применяется (частота сбрасывается только RESET/entry).
- **Click по значению** (readout) = numeric entry: то же поле 92×30/96×30 превращается в редактор,
  текст выделяется целиком, курсор текстовый; принимаются точка и запятая как разделитель;
  Enter/Tab = commit (Tab уходит дальше по focus-порядку), Esc = cancel; значение клампится в диапазон;
  невалидный ввод = откат к прежнему значению и вспышка границы #454C58 на 300 ms (без нового цвета ошибки).
- **Колесо** (предложение, требует утверждения D4): 0.1 за notch, Shift+колесо 0.01; Trim 0.1 dB / 0.01 dB.
- **Клавиатура**: Tab — порядок focus: частоты (одна остановка radiogroup) → Boost → Boost value →
  Attenuation → Atten value → Trim → Trim value → EQ IN → A → B → COPY → RESET.
  На ручке: Up/Right +0.1, Down/Left −0.1, Shift+стрелка ±0.01, PageUp/PageDown ±1.0, Home/End = min/max
  (Trim: шаг 0.1 dB, Shift 0.01 dB, Page 1 dB). В radiogroup частот стрелки переключают выбор без commit-жеста
  (каждое переключение — обычный parameter change). Space/Enter на EQ IN, A/B, COPY, RESET — активация.
- **focus-visible**: кольцо 2 px #8AB4F8, offset 2 px, на всех интерактивных элементах; показывается только
  при клавиатурном/programmatic focus (семантика `:focus-visible`), не при mouse-click; во время mouse-drag кольцо не рисуется.
- **Hover**: границы кнопок/readout → #454C58, текст → #ECEEF1; тело ручки граница → #5A626E; переходы 120–150 ms;
  `prefers-reduced-motion` / настройка хоста отключает анимации переходов (значения меняются мгновенно).
- **EQ IN off**: коррекция bypass; контролы остаются редактируемыми (можно настроить «впрок»), без dimming.
  Состояние различимо не только цветом: ON — заполненный LED ⌀8 + текст; OFF — полый LED (кольцо 1.5 px) +
  текст (вариант надписи — решение D3) + фон/граница поверхности вместо зелёных.
- **A/B (PROPOSAL)**: два банка параметров в состоянии плагина (freq, boost, atten, trim); активный банк
  зеркалируется в host-параметры обычными parameter change; переключение банка — один gesture.
  **COPY (PROPOSAL)**: активный банк → другой банк (одним gesture, с host-undo). **RESET (PROPOSAL)**:
  активный банк → defaults (30 Hz / 0 / 0 / 0.0 dB), одним gesture. Неактивный банк визуально не показывается
  значениями (только буква) — сравнение на слух, без фейковых «preset»-списков.
- **Disabled**: отдельного disabled-состояния у контролов нет; host-bypass отображается как EQ IN off
  (предложение; поведение против host bypass требует проверки на этапе 7, не заявляется сейчас).

## 8. Масштабирование и HiDPI (PROPOSAL)

- Логический холст 960×340; вся графика векторная (мастер — `mockup.svg`; в JUCE — paths/компоненты),
  растровых ассетов нет. Итоговый размер = logical × userScale × osDpiScale.
- UserScale: непрерывный uniform 0.75–2.0 через resize-глиф в подвале и жест угла окна; **без reflow** —
  композиция не перестраивается, сохраняется мышечная память. Окно: min 720×255, max 1920×680.
- HiDPI: рендер в физических пикселях (JUCE Desktop display scale); размеры шрифтов = logical × scale,
  округление до device-пикселя; волосяные линии 1 px снапятся к device-сетке (offset 0.5), чтобы не мылиться.
- Дробные scale не меняют пороги hit-area: минимальная физическая высота кнопки частоты ≥ 28 px
  (при 0.75 = 28.5 px logical→device при dpi 1 — на границе, поэтому min scale 0.75, решение D5).
- PNG-экспорты — только для ревью; продуктовый рендер не использует PNG.

## 9. График АЧХ и запреты

- В направлении A графика **нет**. Если график добавляется позже (или в сравнительном B), любая кривая
  обязана нести постоянный бейдж «DEMO · ILLUSTRATIVE CURVE · NOT MEASURED · NOT DSP» до появления
  проверенного DSP и измеренной АЧХ; ось dB допустима только для графика отклика, никогда для Boost/Atten.
- Запрещено и отсутствует в макетах: HF-секция; списки пресетов; неподтверждённые режимы (oversampling,
  character, linear phase и т.п.); копирование trade dress UAD/Pultec; заявления о точной эмуляции железа
  или о подтверждённом качестве звучания.
- Надписи PROPOSAL обязательны у Output Trim и у кластера A/B/COPY/RESET до утверждения (D1, D2).

## 10. Решения, требующие утверждения пользователем

- **D1. Output Trim.** Включать ли в MVP; диапазон −12…+12 dB, default 0, линейный закон. Альтернатива:
  отложить до измерений makeup-тракта эталона. Сейчас помечен PROPOSAL в макете.
- **D2. Механика A/B/COPY/RESET.** Предложено: два банка в состоянии, активный зеркалируется в host-параметры,
  COPY = активный→другой, RESET = активный→defaults, каждый одним undo-gesture. Влияет на STATE_FORMAT
  (версионирование) — утверждать до этапа 7. Альтернатива: momentary-compare без хранения банка.
- **D3. EQ IN off.** Надпись «EQ OUT» + полый LED + текст #A7AEB8 (исправляет 4.36:1) против сохранения
  «EQ IN» с полым LED; и подтверждение, что контролы остаются редактируемыми при off.
- **D4. Чувствительности.** Drag 200 px / 240 px, fine ×0.1, клавиатурные шаги 0.1/0.01/1.0, колесо 0.1
  (Shift 0.01). Утвердить числа или заменить; колесо можно отключить совсем.
- **D5. Resize.** Непрерывный uniform 0.75–2.0 без reflow против дискретных ступеней (100/125/150/200%);
  min/max окна 720×255 / 1920×680.
- **D6. Границы интерактивных элементов.** Поднять до #6B7482 (≥3:1 non-text) против текущих волосяных
  #2E333C/#454C58 (1.93:1): компромисс «приборная деликатность» vs формальная доступность границ.
- **D7. DEMO-график сейчас или позже.** Рекомендация: позже (A без графика); если сейчас — переиспользовать
  plot-фрейм B с обязательным бейджем и отдельным гейтом маркировки.
- **D8. Гранулярность отображения/ввода.** Display 2 знака для 0–10 и 1 знак для dB; entry-шаг 0.01;
