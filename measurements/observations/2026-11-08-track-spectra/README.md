# Захваты 8 ноября 2026 — REW, микрофон в комнате

Статус: **наблюдение, НЕ измерение эталона**. К Pultec EQP-1A LF MVP отношения не имеют.

Происхождение: предоставлены пользователем 8 ноября 2026. Программа REW, вход — измерительный микрофон в комнате; на входе sweep-сигнал REW. Измерения названы «1», «2» (две разные дорожки REAPER, проигранные в комнату) и «1+2» (сумма). UADx Pultec EQP-1A в цепи этих измерений **не стоял** (подтверждено пользователем).

Характер кривых согласуется с акустическим трактом: гребёнка провалов выше 1 kHz (отражения комнаты), пики басовых мод около 65/95/135 Hz, шкала дБ SPL. Передаточная функция плагина была бы гладкой кривой.

Зачем хранятся: чтобы эти кадры не использовались как доказательство о поведении плагина; возможное применение — калибровка мониторинга/комнаты (вне scope этого проекта).
